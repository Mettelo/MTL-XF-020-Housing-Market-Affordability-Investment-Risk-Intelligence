# Agreed Acceptance Criteria

1. **AC1:** Every geography and period in the curated model uses documented HPI definitions and granularity.
2. **AC2:** At least five selected geography/period values reconcile directly to the frozen HPI source.
3. **AC3:** No output labels an area unaffordable solely from house-price level or growth.
4. **AC4:** Priority areas require multiple documented indicators or an explicit exception rationale.
5. **AC5:** Any composite market-pressure score exposes all components and weights and includes sensitivity analysis.
6. **AC6:** Property-type and buyer-type comparisons use compatible source measures and do not mix incomparable series.
7. **AC7:** The dashboard states clearly which conclusions are market-pressure findings versus affordability hypotheses.
8. **AC8:** A reviewer can reproduce the historical HPI model, priority segmentation and validation outputs from the frozen source without undocumented manual edits.

## Sign-off Rule
Repository files existing is not enough. The panel must verify these criteria from evidence.
