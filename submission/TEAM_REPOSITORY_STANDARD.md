# Mandatory Team Repository Standard

Create `MTL-XF-020-<team-name>` under the **Mettelo GitHub organisation** and add every team member using their individual GitHub account.

Required delivery areas include: data, discovery, data governance, data model, data quality, KPI catalogue, analysis, decision framework, assurance/UAT, technical handover, SQL/source code, notebooks, dashboard, executive deliverables and final submission.

Use issues, meaningful commits, branches, PRs and reviews where practical. A single bulk upload by one member is not appropriate evidence of multidisciplinary delivery. `CONTRIBUTIONS.md` records actual contribution; commit count alone is insufficient.
