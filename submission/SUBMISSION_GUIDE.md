# Submission Guide

1. Create `MTL-XF-020-<team-name>` under Mettelo.
2. Add all team members individually.
3. Establish the required delivery structure.
4. Work collaboratively through GitHub throughout the engagement.
5. Complete D1–D12.
6. Verify source reproducibility, governance, analysis, UAT, limitations and contribution evidence.
7. Complete `submission/FINAL_SUBMISSION.md`.
8. Tag `v1.0-mettelo-submission`.
9. Submit the repository URL to Mettelo.
