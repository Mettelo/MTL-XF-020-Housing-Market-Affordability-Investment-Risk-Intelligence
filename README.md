# MTL-XF-020 — Housing Market Affordability, Development & Investment Risk Intelligence

**Mettelo Project Studio — Cross-Functional Delivery Series**

| Field | Detail |
|---|---|
| Client | Confidential Regional Housing & Economic Development Board |
| Sector | Housing / Economic Development / Investment |
| Duration | 8 weeks |
| Recommended team | 6–8 |
| Sponsor | Director of Housing Strategy |
| Engagement | Simulated confidential-client engagement |

The board faces pressure to support housing supply and affordability but current reporting over-focuses on headline prices. Leadership cannot consistently separate structural price growth, transaction activity, property mix, buyer type and geographic variation when deciding where intervention or further investment analysis is justified.

**Commissioned decision:** Which housing-market areas show the strongest evidence of sustained affordability and market-pressure concerns, and where should development, policy or investment teams investigate first?

This is an end-to-end multidisciplinary engagement rather than a dashboard-only exercise.

Start with the project, governance, data and submission documentation in this repository. Each team creates its delivery repository under the **Mettelo GitHub organisation** and adds every team member using their individual GitHub account.
